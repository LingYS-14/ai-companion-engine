# 路线图

## 当前状态（2026-11）

内核已经可以长期在线运行：tick、记忆、意图、睡眠、双通道、网页能力、模型分层都已落地并通过工程门禁（285 个测试文件 / 3437 条用例 / 11 道门禁）。

已知的诚实边界：

- 夜间 dream 落库（memory L1）尚未开启，仍在 shadow 阶段；需要 ≥3 夜样本校准阈值。
- SelfModel（长期自我叙事）未启用：现有真实互动样本远低于门槛（≥8 次互动、≥7 天、event-specific 记忆 ≥15 条）。
- 网页抓取只做基础 SSRF 校验，无 DNS rebinding / robots / 缓存 / 并发限制。
- 记忆检索仍是加权打分 + 来源过滤，没有向量检索或多跳图；数据量小，当前够用。
- 部分模块仍有历史债务：`plugin/index.ts`、`plugin/runtime.ts` 偏大；分层边有 6 条冻结债务。

## 下一批（按优先级）

### A. 装配安全（最高优先级）
- 装配层 smoke 测试：`main.mjs` 的闭包/接线在测试里跑一遍真实启动路径。
- dist 导入 parity：校验 `dist/` 导出与源码一致，避免「tsc 通过、运行时缺导出」。
- 跨闭包状态收敛：禁止装配点之间靠外层 `let` 共享可变状态。

### B. 成本与缓存
- 前缀稳定化：把每拍变化的字段从 system prompt 前缀挪走，提高缓存命中（命中价差约 50 倍）。
- 日预算（建议 $3）与单拍异常告警。
- 谷时调度：learn / consolidation / dream 尽量安排在谷时。

### C. 记忆与认知
- 双时态 + supersedes（不物理删，冲突追加新条并失效旧条）的 shadow 模式。
- 检索打分加入 importance 与 source_trust。
- 100 条回归集（LongMemEval 五类能力）作为验收底座。
- 写决策（ADD/UPDATE/DELETE/NOOP）替代纯 Dice 去重。
- 困惑度/惊讶度驱动的回放与再巩固。

### D. 认知架构
- Workspace 竞争广播（每拍选 1–2 条进入提示词，落选抑制数拍）。
- 预测-惊讶-元认知回路（用预测误差驱动记忆权重与好奇）。
- 夜间叙事自我（reflection → 周级自我重述），替代任何形式的固定人设。

### E. 工程债务
- 抽公共 `renameWithRetry` / 原子写层（现有 4+ 份内联拷贝）。
- append-only 事件日志 + 确定性回放。
- 拆分 god 文件，收敛 `engine/config.ts` 的 64+ 旋钮。

## 明确不做

- 不引入向量数据库/图数据库（数据规模不匹配，收益低）。
- 不引入 Temporal / LangGraph 等外部编排（单写者串行 tick 更简单可靠）。
- 不做多角色/多租户（单用户内核）。
- 不发布任何真实用户数据、镜像或聊天记录。
